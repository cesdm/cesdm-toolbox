# Guides

The [tutorial](../tutorial/index.md) shows the whole exchange once; [Concepts](../concepts/index.md) explain why it works. The guides are recipes for one task each. Pick the one that matches your situation:

| Your situation | Guide |
|---|---|
| You have files or a tool and want to exchange with other groups | [Write an adapter](write-an-adapter.md) |
| You start without existing files: a new study, a test system, a generated model | [Build a model directly](build-a-model.md) |
| You write your own scripts or notebooks and want shorter code | [Write models with the proxy API](proxy-api.md) |
| Your study includes gas, heat or hydrogen, not only electricity | [Carrier domains](carrier-domains.md) |
| The core lacks a class or attribute your study needs | [Extend the schema](extend.md) |

Complete worked examples from other fields and real datasets are in [Use cases](../use-cases/index.md).
