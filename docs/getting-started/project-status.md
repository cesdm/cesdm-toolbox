# Project Status

CESDM is a **research / beta** project (SWEET-CoSi). Schemas and APIs evolve. Treat releases as methodology demonstrators unless you pin a version.

---

## What is available, experimental, or planned

```text
Project status: Research / Beta

✓ Core semantic model
✓ Electricity domain
✓ Multi-carrier model (gas, heat, conversion)
✓ Validation
✓ YAML / Frictionless / HDF5 exchange
✓ PyPSA adapter
✓ pandapower / MATPOWER adapters

△ API stability
△ Documentation consolidation
△ Broader external adoption

○ Graphical model explorer
○ High-level Model() convenience API
```

| Status | Meaning |
|--------|---------|
| **✓ Available** | You can use this in a study today |
| **△ Experimental** | Works, but names or layout may still change |
| **○ Planned** | Not implemented yet |

---

## What this means for you

- **Modellers:** The electricity and multi-carrier vocabulary is usable. Pin the toolbox version if you need a stable snapshot.
- **Tool integrators:** Adapters exist; expect interface tweaks as schemas evolve.
- **Readers:** The [CESDM in 5 Minutes](cesdm-in-5-minutes.md) page and [Build a Small Electricity System](first-model-simple.md) are the intended entry path.

See also [CESDM vs other tools](cesdm-vs-others.md) and [Disclaimer](disclaimer.md).
