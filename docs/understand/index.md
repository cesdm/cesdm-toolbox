# Understand CESDM

How CESDM represents an energy system — start here after [your first model](../get-started/first-model.md).

CESDM is a schema-driven, tool-independent **semantic** framework for interoperable energy-system modelling. It is not introduced as an ontology. [Entities and relationships](entities-and-relationships.md#schema-semantics-and-ontology) explains the difference.

The current schema version is **1.0.0**. What changed is in the [release log](../community/changelog.md); stability tiers are in [governance](../develop/governance.md) and the [roadmap](../community/roadmap.md).

- **[Entities and relationships](entities-and-relationships.md)** — objects/entities, facts/attributes and connections/relationships (read this first)
- **[Schemas](schemas.md)** — the allowed types and fields
- **[Profiles](profiles.md)** — hourly and other time series
- **[Libraries](libraries.md)** — shared technologies and carriers you import
- **[Carrier domains](carrier-domains.md)** — electricity, gas, heat, …
- **[Related work](related-work.md)** — why CESDM exists beside CIM/CGMES, ESDL, oemof and analysis tools
